Compositional Generalization in Embodied Foundation Models via Multimodal Subgoal Prompting and Flow-Based Action Execution

Generalist robot policies scale to thousands of tasks and still fail the test that defines embodied intelligence: a long-horizon task on an unseen object, with an unseen morphology, in a world that does not hold still. The thesis: generalization is not produced by scaling a monolithic vision-language-action network — it is produced by structuring the problem into a steerable hierarchy: a VLM that plans in dense visual subgoals, a flow-matching expert that executes between them, a steerable conditioning layer with a certified no-jerk bound, and a runtime formal-verification safety envelope.

01 /

The thesis

Pure hardcoded logic fails because the real world has infinite variance — the state space of a deformable cable or a draped textile cannot be enumerated. Pure neural nets fail because they lack strict spatial-temporal anchors — a monolithic forward pass has no mechanism for re-anchoring when the world moves, no channel for a human to correct a subgoal mid-task, and no certificate that the executed trajectory stays safe.

The way through is to structure the problem. A high-level VLM provides semantic context and dense visual subgoal predictions; a low-level continuous-time flow-matching expert provides high-frequency, smooth action execution; between them, a steerable conditioning layer admits corrections with a provable smoothness envelope; around all of it, a control-barrier-function filter verifies every action at runtime.

02 /

The paradigm

COMPOSITION

Subgoal factorization, not weight scaling

The policy factorizes at the subgoal level: each flow segment is conditioned on one visual keyframe, so skills compose across tasks — the composition happens in the conditioning, not inside a single weight matrix.

STEERABILITY

Corrections with a certified no-jerk bound

Human nudges, world-model replans, and constraint setpoints enter the flow through bounded-Lipschitz gates. A Grönwall-type bound certifies how far a correction may move the trajectory — steering without jerks, by construction.

VERIFICATION

A runtime safety envelope, not a hope

A control-barrier-function QP filter projects every commanded action onto the admissible set with a forward-invariance guarantee. Steerability is admitted only through the filter — corrections reshape the trajectory inside the certified tube.

03 /

The architecture

A 3B+ vision-language planner Λφ maps instruction and observation to dense subgoals g1:K = (κk, ℓk) — predicted keyframes plus language steps. The flow-matching expert vθ(xs, s, c) integrates a learned velocity field over an ODE path with 2–10 steps at 50 Hz, in a canonical cross-embodiment action frame. Steering signals enter through the SMC adapter; the CBF–QP filter gates every action before the actuators.

vθS(xs, s, c, u)  =  vθN(xs, s, c) + Σj λj(xs, s) · vθj(xs, s, uj) (1)

Anchored steering: vθj(·, u0) ≡ 0 recovers the nominal field exactly; gates λj = σ(wjTφ) engage softly. Grönwall: ‖xS − xN‖ ≤ (M/Lv)(eLvΔs − 1). Full formulation in the proposal.

04 /

The benchmarks

Three tasks selected to be maximally chaotic — non-rigid, high-entropy, long-horizon — in ways that defeat both hardcoded logic and monolithic imitation. Zero-shot protocol: entire morphologies, material regimes, and tool classes held out of every training source; intervention rate and jerk reported as costs.

TASK A

Cable untangling

A deformable cable in a crossed configuration must reach a knot-free target. Held-out: stiffness, length, crossing topology, friction.

non-rigid contact-rich
TASK B

Textile folding

Fold a fabric that shifts under its own drape — subgoal images go stale and must be re-anchored. Held-out: material classes, fold geometry.

shifting state replan-heavy
TASK C

Adaptive tool use in clutter

Retrieve, lever, or pull with tools never seen. Held-out: tool morphology classes, clutter density, affordance composition.

semantic + geometric clutter
